Lock the club data

This page turns the club's data into an encrypted data.js file. Only someone with one of the passwords can read it, and each password opens a different version of the app. Everything happens on this computer: nothing is sent anywhere.

1. Start from something

Open your current data.js with the admin password to edit it, or start from the demo data.

2. Edit the data

The format is explained in README.md. Dates are written YYYY-MM-DD, kick-off times 14:00, and scores are always our goals first, e.g. 2-1.

3. Choose the passwords

Capitals don't matter. Each must be different.

4. Lock it

Put the downloaded data.js next to index.html, replacing the demo one, and upload it. Phones pick up the change the next time they open the app.
